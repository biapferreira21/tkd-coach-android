# TKD Coach

Aplicação Android de treino de Taekwondo, com treinos existentes e personalizados, catálogo de exercícios, instruções por voz, fotografias de apoio e Poomsae passo a passo.

## Funcionalidades

- Treinos completos e treinos personalizados
- Edição, nomeação, repetição, loops e descansos
- Ordem manual ou baralhada em cada execução
- Taegeuk 1–8 e Koryo passo a passo
- Exercícios de Taekwondo, boxe, kickboxing, força, pesos, cardio e alongamentos
- Temporizador, progresso da sessão e tempo restante
- Voz Android e integração opcional com ElevenLabs
- Funcionamento offline para o conteúdo incorporado

## Requisitos

- Android Studio
- Android SDK compatível com `compileSdk 37`
- Java 17

## Executar

1. Abrir esta pasta no Android Studio.
2. Aguardar a sincronização do Gradle.
3. Ligar um dispositivo Android ou iniciar um emulador.
4. Executar o módulo `app`.

## Gerar uma APK de teste

No Android Studio, selecionar **Build → Build APK(s)**. O ficheiro será criado em `app/build/outputs/apk/debug/`.

## ElevenLabs

A chave ElevenLabs não está incluída no código. É introduzida pela utilizadora dentro da aplicação e guardada localmente no dispositivo. Nunca deve ser adicionada ao GitHub.
